# ML Quest: our own piano transcription model

Goal: a small piano transcription model trained by us, for KeySync, that fits
in the 512MB free Render container. No small ready-made piano model exists
publicly (checked Sep 30, 2026: PARcompact, HRplus, HPPNet released no
checkpoints), so we train our own.

## Where things stand (Oct 1, 2026, early morning)

Production is switching to a fp32 ONNX export of Kong's note model with
2.5-second windows (see ../transcribe-service/onnx_notes.py). int8
quantization was tried and rejected: it crushed the onset/frame outputs
(max diff 0.13 vs fp32) and produced zero notes on real audio. fp32 is the
verified path: ~360MB peak, ~428MB for the full Flask service on a 129s
clip, safe under the 512MB free tier. Torch is no longer installed at all.

This folder is the real thing: training a compact model from scratch.

## The plan

1. **Learn how it works** (together, plain language): what a spectrogram is,
   what the model predicts (frame/onset/offset rolls), how rolls become notes.
2. **Walk through the training code**: `upstream-training/` is Kong's MIT
   training repo (cloned, not modified except by patch_training_repo.py).
3. **First experiment**: train the compact model on 14h of MAESTRO (2015
   split) using the free Kaggle GPU notebook. A few hours, real numbers.
4. **Evaluate honestly**: note F1 on the MAESTRO test split. Compare against
   Kong's 0.939 and our quantized baseline.
5. **Ship it**: export the winner to ONNX + int8, swap it into the service.

## Files

- `kaggle-train.ipynb` - the full pipeline for a free Kaggle GPU: setup,
  data, train, evaluate, export. Generated by `gen_notebook.py`.
- `conformer2d_compact.py` - compact model (~4.6M params vs 150M+): same
  architecture family as Kong's Conformer2D, shrunk (256-wide, 2+2 layers,
  4 heads). Verified: builds, forward pass gives correct roll shapes.
- `compact-conformer.yaml` - training config for the compact model.
- `patch_training_repo.py` - copies the compact model into Kong's repo and
  teaches `train.py` about it (tested against the cloned upstream).
- `fetch_maestro_subset.py` - downloads only chosen MAESTRO year folders
  from the official 108GB zip via HTTP range requests (tested: listing +
  csv fetch work; full-year download not yet run).
- `export_compact_onnx.py` - checkpoint -> ONNX fp32 -> int8 + numeric check.
- `upstream-training/` - Kong's training repo (git clone, MIT). Not ours;
  re-clone to refresh.

## The compact model at a glance

Mel spectrogram (256 mels) -> 2 conv blocks -> 2 conformer encoder blocks ->
2 conformer decoder blocks -> frame/onset/offset rolls (100 fps, 128 pitches).
4.61M parameters, ~18MB fp32, ~5MB int8. Training target: 100k steps,
batch 8, AdamW 1e-4, on a Kaggle T4 (~6-10h).

## Rules for this quest (Pratham's)

- Learn first, then build. If he does not learn anything, it does not happen.
- Real metrics, not vibes: note F1 on MAESTRO test, before/after numbers.
- Zero money: free GPUs (Kaggle/Colab), free data (MAESTRO), free hosting.
